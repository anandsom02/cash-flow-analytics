# Cash Flow Analytics & Forecasting

## Project Overview
This project analyzes cash inflow, cash outflow, expenses, and transaction performance for a fictional company, NovaTech Solutions Pvt. Ltd. The goal is to identify cash flow trends and build an interactive dashboard to support financial decision-making.

## Tools & Technologies
- **Python:** Data cleaning and exploratory data analysis
- **Pandas & NumPy:** Data manipulation and calculations
- **Matplotlib & Seaborn:** Data visualization
- **MySQL:** Data storage and SQL analysis
- **Power BI:** Interactive dashboard and KPI reporting
- **DAX:** Financial measures and calculations
- **Google Colab:** Python development environment

## Dataset
The project uses a synthetic dataset containing 10,000 transactions from January 2024 to December 2026.

Key columns include:
- Transaction ID and Date
- Transaction Type and Category
- Amount and Payment Method
- Department and Customer/Supplier
- Transaction Status and Description

## Key KPIs
- Total Cash Inflow
- Total Cash Outflow
- Net Cash Flow
- Total Transactions
- Successful Transactions
- Transaction Success Rate

## Analysis Performed
- Monthly and yearly cash flow analysis
- Year-over-year net cash flow comparison
- Expense category analysis
- Transaction status analysis
- Interactive date and transaction filters

## Key Findings
- Completed cash inflow: approximately ₹37.03 crore
- Completed cash outflow: approximately ₹27.42 crore
- Net cash flow: approximately ₹9.61 crore
- Total transactions: 10,000
- Completed transactions: 9,012
- Transaction success rate: 90.12%

These findings describe the synthetic dataset and are not actual company financial results.
